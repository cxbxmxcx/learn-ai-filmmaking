# Learn AI Filmmaking: seven prompts, seven films

Companion repository for the seven-day **Learn AI Filmmaking** series by Micheal Lanham. Each article teaches one layer of directorial control (the shot, the look, the camera, the character, the cut, the effect, and finally all of them at once) and ends with a short film made from **a single AI generation**: one prompt, one take, native sound, no editing.

## How the films were made

- Video: Seedance 2.5 on fal, 720p, 16:9, native audio, one generation per film. The exact settings, prompt and returned seed for each film are in `prompts/`.
- Infographics in the articles: Nano Banana Pro, from the prompts in the same files.
- Nothing was edited, upscaled or re-cut. What you see is what the model returned.

## Layout

- `docs/` is the GitHub Pages site: one watch page per film, the films, posters and previews.
- `prompts/` holds every prompt used, per day.

All films in this repository are AI-generated.
